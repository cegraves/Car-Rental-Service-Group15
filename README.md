## Project Overview

The Car Rental Service is a web-based application designed to allow users to browse available rental vehicles and create vehicle bookings.

The project was developed throughout several phases:

- Week 1: Planning and requirements gathering
- Week 2: System architecture and design
- Week 3: Prototype development
- Week 4: Implementation, testing, and reflection

## Technology Stack

- HTML/CSS – Frontend
- Python / Flask – Backend and web application
- MySQL – Database
- GitHub – Version control and team repository
- 

## Current Prototype Features

The current prototype includes:

- Displaying available rental vehicles
- Vehicle images and daily rental prices loaded from the database
- Vehicle selection and booking form
- Pickup and return date selection
- Syracuse email validation for bookings
- Booking information stored in the MySQL database
- Login/Registration System(we are still working on that) 

## Database

The current database design contains:

- `user`
- `category`
- `vehicle`
- `booking`
- `payment`

## Project Architecture

The project follows a basic three-layer structure:

1. **Presentation Layer** – HTML/CSS pages displayed to the user
2. **Application Layer** – Python and Flask application logic
3. **Data Layer** – MySQL database

The Flask application acts as the connection between the website and the database.
